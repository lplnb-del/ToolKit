# ToolKit - 产品需求文档 (PRD)

## 1. 产品概述

### 1.1 产品名称
**ToolKit** - 开发者工具集合网站

### 1.2 产品定位
一个纯静态、开源的在线工具集合网站，为开发者和日常办公人员提供便捷、安全的工具服务。所有工具均在浏览器端运行，无需后端服务器，保护用户数据隐私。

### 1.3 目标用户
- 前端/后端开发者
- 产品经理、设计师
- 日常办公人员
- 学生和技术爱好者

### 1.4 核心价值
- **隐私安全**：所有数据处理在本地完成，不上传服务器
- **即用即走**：无需注册登录，打开即用
- **快速访问**：常用工具一键直达
- **开源免费**：代码开源，永久免费使用

## 3. 非功能需求

### 3.1 性能要求
- 首屏加载时间 < 2s
- 工具页面切换 < 300ms
- 支持离线使用（PWA）

### 3.2 兼容性要求
- Chrome 90+
- Firefox 88+
- Safari 14+
- Edge 90+

### 3.3 安全要求
- 所有数据处理在浏览器端完成
- 不上传用户数据到服务器
- 敏感操作（如密码生成）使用加密安全的随机数

### 3.4 可访问性
- 支持键盘操作
- 支持屏幕阅读器
- 符合 WCAG 2.1 AA 标准

## 5. 功能详细说明

### 5.1 首页功能
- **热门工具**：展示使用频率最高的 8 个工具
- **最近使用**：记录用户最近访问的 8 个工具（LocalStorage）
- **分类导航**：按类别展示所有工具
- **搜索功能**：支持工具名称和关键词搜索

### 5.2 工具页面通用功能
- **输入/输出区域**：清晰的输入输出分区
- **一键复制**：结果一键复制到剪贴板
- **历史记录**：保存最近 20 条操作记录
- **示例数据**：提供示例方便快速体验
- **快捷键支持**：常用操作支持键盘快捷键

### 5.3 收藏功能
- 用户可收藏常用工具
- 收藏数据保存在 LocalStorage
- 收藏页展示所有收藏的工具

## 6. 技术约束

### 6.1 纯前端限制
- 无法直接操作文件系统
- 大文件处理受内存限制
- 无法执行系统命令

### 6.2 浏览器限制
- 部分加密算法需使用 Web Crypto API
- 图片处理依赖 Canvas API
- 文件下载使用 FileSaver.js
